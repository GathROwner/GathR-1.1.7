The map passes its measured rail width to the control; the hint shrinks within safe horizontal bounds. Its content scrolls on shorter screens or large text, and the private/public descriptions can wrap. This replaces the first iteration's layering-only fix. A transparent Pressable behind the hint consumes the first outside tap, closes the hint and disappears; the tap does not select an underlying marker or interest pill. The × remains. Normal ready-button taps retain the prepared place chooser. Hold the button for readiness details at any stage, or use the screen-reader action. Unready-button taps still show details and now toggle them closed. The touch target gains four points of hit slop. Details close when focus, foreground, enabled state or user changes.

The ready button gets a one-second white sweep after a 1.2-second initial delay, then at most once every 90 seconds. The decorative overlay cannot intercept touches. It uses the native animation driver without an interaction handle; timers and animation stop when inactive, unready, checked in, or the popup/chooser is open. Returning from an interruption retains a cooldown. Reduce Motion suppresses it. The cue follows actual private-check-in availability; it does not imply public-place preparation is complete or advance either ring.
